# 60일주 참고 데이터 및 상세 리포트 활용

## 목적

상세 사주 리포트의 `1. 일주론`에서 선택된 날짜의 일주에 맞는 설명을 제공합니다.
현대인의 사주산책 일주론 카테고리 1~4페이지에 등록된 60개 글을 출처로 확인했으며,
원문을 복제하지 않고 서비스 문체의 요약 데이터로 재구성했습니다.

## 저장 위치

- 실제 서비스 데이터: `lib/saju/day-pillar-profiles.ts`
- 상세 리포트 연결: `components/lucky-day-detail-dialog.tsx`

`static`은 브라우저가 URL로 직접 내려받는 이미지 같은 공개 자산에 적합합니다. 이 데이터는
TypeScript 모듈로 두어 60개 키의 누락을 빌드 단계에서 검사하고, 별도 네트워크 요청 없이 정적
앱 번들에서 바로 조회하도록 했습니다.

## 데이터 구조

각 일주는 다음 값을 가집니다.

| 필드 | 용도 |
| --- | --- |
| `ganzi`, `name` | 한자·한글 일주 식별자 |
| `image` | 일주를 설명하는 대표 물상 |
| `traits` | 기본 성향 |
| `strengths` | 강점과 활용 방향 |
| `cautions` | 균형을 위해 살필 점 |
| `careerThemes` | 적성·진로 참고 키워드 |
| `dayBranchTenGod` | 일지 본기를 기준으로 산출한 중심 십성 |
| `twelveStage` | 일간이 일지에서 만나는 십이운성 |
| `hiddenStems` | 일지 지장간 |
| `notablePatterns` | 천을귀인·백호·괴강·간여지동 등 원문 대조 특징 |
| `summary` | 상세 리포트에 바로 표시하는 자체 요약 |
| `detail` | 성향·재능과 진로·일과 재물·관계·균형 포인트의 상세 해설 |
| `sourceUrl`, `sourcePage`, `sourceReviewedAt` | 개별 참고 글, 카테고리 페이지, 원문 대조일 |

총 60개이며 `DAY_PILLARS`와 `SEEDS`는 `Record<DayPillar, ...>` 타입으로 서로 완전성을
검사합니다. 개별 출처 링크는 각 프로필의 `sourceUrl`에 저장되어 상세 화면에서도 확인할 수
있습니다.

## 리포트 동작

1. 선택된 날짜의 `day.dayPillar`로 `getDayPillarProfile()`을 호출합니다.
2. 내장 기본 해설은 해당 프로필의 `summary`와 다섯 가지 `detail` 해설, 단식 해석 주의
   문구를 표시합니다.
3. `NEXT_PUBLIC_SAJU_REPORT_API_URL`이 있으면 구조화된 `dayPillarProfile`도 보호 API에 함께
   전달합니다. 서버 측 생성 모델은 이 데이터를 근거로 전체 사주 구조에 맞춰 문장을 조정할 수
   있습니다.
4. 상세 화면의 출처 링크에서 해당 일주의 참고 글을 열 수 있습니다.

## 해석 원칙

- 일주론은 성향의 가능성을 설명하는 참고 정보이며 성격, 건강, 관계, 직업을 단정하지 않습니다.
- 실제 리포트에서는 월령, 주변 간지, 오행 기도, 신강·신약, 용신을 함께 반영합니다.
- 출처 글의 문장을 장문으로 저장하거나 그대로 노출하지 않고, 물상과 해석 요점을 자체 문장으로
  요약합니다.
