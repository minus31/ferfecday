# 통합 사주해설 지식 DB 및 검색

## 목적

일주론과 별도로 원국의 오행·신강도·십성·격국·십이운성·십이신살·양육 해설 및
제1~8대운의 흐름을 조회하고, 마지막 단계에서만 하나의 상세 사주해설로 조합합니다.

## 원본 자료

- `docs/reference/ThingsforMaking_saju_explanation.xlsx`
- `docs/reference/대운DB_요건서_간략.docx`

원본은 수정하지 않습니다. SHA-256을 기록한 생성물을 사용하므로 원본이 바뀌었는지 확인할 수
있습니다.

## 생성 데이터

| 파일 | 내용 |
| --- | --- |
| `lib/saju/data/explanation-rules.json` | Excel의 5개 콘텐츠 시트에서 실제 값이 있는 166개 규칙 |
| `docs/generated/대운DB_요건서_추출.md` | Word 문서를 추적 변경 포함 Markdown으로 추출한 검토용 문서 |
| `lib/saju/daewoon-knowledge.ts` | 기간·등급·용신 강화/약화·성별·신살 분기를 실행 가능한 규칙으로 정리 |

원본이 변경되면 다음 명령으로 생성물을 다시 만듭니다.

```bash
python3 scripts/extract-saju-knowledge.py
```

Python 패키지에 의존하지 않고 XLSX의 OOXML을 읽으며, DOCX는 `pandoc
--track-changes=all`로 추출합니다.

## 검색 경계

### 일주론 검색

- 모듈: `lib/saju/day-pillar-profiles.ts`
- 키: 60갑자의 일주 간지
- 함수: `getDayPillarProfile(ganzi)`

### 통합 해설 지식 검색

- 모듈: `lib/saju/explanation-knowledge.ts`
- 함수: `searchExplanationKnowledge(query, options)`
- 검색 대상: 콘텐츠 ID, 테마, 카테고리, 제목, 트리거, 명리 근거, 본문
- 필터: `theme`, `category`, `limit`

두 검색기는 서로의 데이터를 조회하지 않습니다.

## 자동 매칭

`matchExplanationKnowledge(day)`는 현재 `LuckyDay`에서 확실히 판정할 수 있는 규칙만 선택합니다.

1. Theme 1 기본: 일간, SI 등급, 오행 구족 여부로 하나를 선택합니다.
2. Theme 1 십성: 5개 역할 기도의 최대·최소 비율과 태과·불급 단계로 선택합니다.
3. Theme 2: 중심 십성, 월지 격국, 일지 십이운성 및 일지 십성에 맞는 재능·직업 규칙을
   선택합니다.
4. Theme 3: 성별, 일지 십이운성·십이신살 조합을 확실히 계산할 수 있을 때만 양육 규칙을
   선택합니다.
5. 원진·귀문·삼형·특정 행운 중첩처럼 현재 직렬화 데이터만으로 확정할 수 없는 트리거는 검색
   DB에는 보존하지만 자동 매칭하지 않습니다.

문자열을 임의로 실행하지 않으며 `eval`을 사용하지 않습니다.

## 대운 해설

`buildDaewoonInterpretations(day)`가 제1~8대운을 다음 순서로 분석합니다.

1. 시작 나이를 10년 단위 기간으로 분류합니다.
2. 원국 Base Score와 대운 유입 Base Score의 차이로 전성기·상승기·관리기·주의기를 판정합니다.
3. 대운 천간과 지지가 용신의 인성·비겁·식상·재성·관성 중 어디에 해당하는지 가중치로
   계산하여 용신 강화/보완을 판정합니다.
4. 20~30대 남명 재성 및 여명 관성 조건이면 관계 문단을 추가합니다.
5. 대운 지지의 십이신살에 해당하는 Theme 4 문구를 추가합니다.

## 최종 리포트

`buildIntegratedSajuReport(day)`가 다음 여섯 영역을 조합합니다.

1. 전반적인 사주 해석
2. 일주론
3. 격국론
4. 평생의 성공과 재능
5. 사주의 특징과 양육 솔루션
6. 10대~80대 대운 흐름

보호 API를 사용하는 경우 선택된 규칙과 대운 분석 결과도 요청 본문에 함께 전달합니다. API가
새 필드를 반환하지 않아도 로컬의 `talent`와 `parenting` 결과는 유지됩니다.

## 표현 원칙

- 사주해설은 성향과 가능성을 설명하는 참고 콘텐츠로 제공합니다.
- 건강 관련 원문 규칙은 의학적 진단이나 치료 지시로 사용하지 않습니다.
- 특정 사건, 질병, 합격, 재산, 배우자 관계를 확정적으로 예언하지 않습니다.
- 자동 판정 근거가 부족한 규칙은 억지로 매칭하지 않습니다.
